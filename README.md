# Omkar — Personal Portfolio

A clean, modern and responsive personal portfolio website for a Full Stack Developer.

## Tech
- HTML5
- CSS3
- JavaScript
- Responsive design
- Google Fonts

## Run
Open `index.html` directly in your browser.

## GitHub Pages
1. Create a repository, for example `omkar-portfolio`.
2. Upload all files from this folder.
3. Go to **Settings → Pages**.
4. Select **Deploy from a branch → main → / (root)**.
5. Save.

## Customize before publishing

Search and replace:
- `Omkar` → your name
- `your.email@example.com` → your email
- GitHub links → your GitHub profile
- LinkedIn links → your LinkedIn profile
- Project `href="#"` → your project URLs
- Skills and project descriptions → your actual skills/projects

## Important
The portfolio currently uses placeholder contact/social links so you can replace them with your real details before publishing.
